Design Research: IRTH Store — Liquid Glass + Modern Minimal Enhancement

TL;DR — IRTH's current Horizon build (ivory/gold/madinah-green, Cormorant + DM Sans, native sections) already matches the luxury-heritage-food pattern used by Bateel, Fortnum & Mason, and To'ak Chocolate — minimal palette, editorial storytelling, restrained typography. The single highest-leverage move: apply liquid-glass translucency only to secondary/transient surfaces (cart drawer, sticky header-on-scroll, quick-view popovers) using settings Horizon already exposes — not as a global background treatment. Global glassmorphism would undercut the calm-heritage positioning; scoped glass reinforces it.

Current State

No live screenshot captured this pass — local browser-automation tooling hit a parameter-serialization bug in this environment. Current state is described from the theme's pushed JSON (verified via shopify theme check + live HTTP fetch): ivory (#F3EFE7) background, ink (#111111) text, madinah-green (#0E2B22) and gold (#B0885E) accents; Cormorant headings / DM Sans body; hero video → heritage story → trust badges → dates collection → gift-boxes collection → marquee → journal. Collection pages already have dedicated hero photography via alternate templates.

Recommendations / Next Steps

1. Scope liquid glass to 3 surfaces only: cart drawer, sticky header, quick-view/popover

Research consensus (LogRocket, Orizon, DesignMonks) is unanimous: glass effects work as a secondary/transient layer — not a persistent background. Horizon already exposes drawer_border_color, drawer_background_color, popover_border_radius, popover_border_color. Add backdrop-filter: blur(16px) + translucent ivory background scoped to .cart-drawer, .header--sticky, .popover in a small new assets/liquid-glass.css.

┌──────────────────────────────┐
│ ░░░ blurred header (scroll) ░░│  ← translucent, only after scroll > 0
├──────────────────────────────┤
│                                │
│   [ opaque product content ]  │  ← zero glass here — full clarity
│                                │
└──────────────────────────────┘
        ┌───────────────┐
        │ ░░ cart drawer ░░│  ← glass slide-in panel, blurred backdrop
        │  item · item     │
        │  [Checkout →]    │
        └───────────────┘

2. Editorial asymmetry on the About/heritage page

Aesop's pattern (Work & Co): asymmetric split layouts, large photography, serif+sans pairing, subtle scroll-fade. Extend the existing media-with-content section type to a dedicated page.about.json with alternating media_position per block.

┌────────────┬─────────────────┐
│            │  Eyebrow         │
│   image    │  Heading         │
│            │  Body copy       │
├─────────────┬────────────────┤
│  Eyebrow    │                 │
│  Heading    │     image       │
│  Body copy  │                 │
└────────────┴─────────────────┘

3. Confirm scroll-reveal is inherited by new sections

animations_reveal_on_scroll is already true in settings — audit that trust badges / heritage story sections inherit it. This is Horizon's native equivalent of Aesop's "images fade in gently as you scroll" — zero custom JS.

4. Shop-by-occasion curation, matching Bateel / Fortnum & Mason

Both lead with occasion-based entry points (Ramadan, corporate, wedding) rather than pure category grids. IRTH already has a Ramadan collection and gift-boxes — add a native collection-list section as occasion tiles.

┌───────┬───────┬───────┬───────┐
│ Ramadan│ Corp. │Wedding│  New  │
│ image  │Gifting│ Gifts │Arrival│
└───────┴───────┴───────┴───────┘

5. Product page: exhaustive craft/heritage detail

To'ak Chocolate and Fortnum & Mason pair the buy box with origin story, tasting notes, pairing suggestions. Add an "Origin & Harvest" accordion row alongside the existing FAQ accordion (product-information already accepts @theme blocks).

6. Mega-menu for bilingual category nav

Aesop's "shoppable navigation" — surfacing categories visually. Fits IRTH's Arabic/English dual-label collections. Worth a follow-up once Arabic is installed as a shop language.

Patterns (table stakes)

  • Soft neutral palette, generous whitespace, product photography as the hero.
  • Serif for headings only, sans for body/UI — matches IRTH's Cormorant/DM Sans split.
  • Storytelling content treated as a first-class page, not a footer afterthought.
  • Subtle, restrained motion — fade/scroll-reveal, not aggressive parallax.

Anti-Patterns

  • Glassmorphism as a full-page background — the #1 flagged mistake across every 2026 source.
  • Oversized "screaming" H1s.
  • Generic 3-equal-card feature rows.

Unique Angle

To'ak Chocolate's homepage opens with a full-screen cinematic video of the harvesting/production process itself — the process is the hero. IRTH's hero video does something similar; worth confirming it's process/place-focused (Madinah groves, hand-selection) rather than a generic product loop.

Findings

The research validates IRTH's current direction rather than calling for a redesign. The gap isn't "more design" — it's applying liquid glass narrowly (drawers/overlays only) and deepening occasion-based storytelling the way heritage-gifting leaders do.
